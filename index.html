Are my API keys safe?

Keys live only in your browser's localStorage and go straight to Groq or Gemini. Use free-tier keys and clear them on shared devices.

Is the vision module a real CNN?

In this static site it uses classical image features plus Gemini vision. The PyTorch ResNet/EfficientNet pipeline belongs in the Python backend from the spec.

Why does the LLM never do math?

Numbers come from deterministic code, and AI summaries are checked against them to catch hallucinations.
